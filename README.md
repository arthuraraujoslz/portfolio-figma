# 🎨 Protótipo de Portfólio Pessoal - Figma

Bem-vindo ao repositório do meu protótipo de portfólio, desenvolvido como atividade acadêmica para a **Trilha Front-end | Design de Experiência**.

## 📌 Sobre o Projeto

Este projeto consiste na criação da interface (UI) e estruturação da experiência do usuário (UX) de um portfólio pessoal. O objetivo é apresentar minha trajetória como estudante de Engenharia de Software, com foco e interesse na área de Engenharia de Dados.

O design foi construído no Figma, utilizando uma identidade visual moderna em tom dark (roxo e preto).

## 🚀 Estrutura do Portfólio

O protótipo atende a todos os requisitos solicitados na atividade:

1. **Apresentação:** Hero section com biografia, trajetória e interesses técnicos.
2. **Stacks / Habilidades:** Organização das tecnologias que já conheço e as que estou aprendendo.
3. **Projetos:** Estrutura inicial ("Em breve") para os projetos futuros.
4. **Página Individual do Projeto:** Navegação funcional ligando a Home aos detalhes do projeto.
